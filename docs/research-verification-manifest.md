# Research Verification & Scientific Quality Audit Manifest

This manifest documents the exhaustive scientific quality audit conducted under **Task 15.1**
evaluating the 100 candidate research datasets proposed in Task 15.

In strict adherence to the project's quality-first policy (*'Quality is more important than reaching exactly 201 records'*),
every dataset was audited for original research provenance, actual machine learning task suitability, accessible data files,
correct modality classification, verified licensing, and duplicate/derivative integrity.

## Audit Outcome Summary

- **Original Published Catalog:** 101 datasets (100% preserved intact)
- **Candidates Audited:** 100 datasets
- **Genuinely Approved:** **61 datasets**
- **Deferred / Needs Review:** **4 datasets**
- **Rejected:** **35 datasets**
- **Final Published Catalog Count:** **162 datasets**

## Scientific Quality Audit Methodology

1. **Distinction Between Papers and Datasets:** In initial automated harvests, deposits containing journal manuscripts, supplemental figures (PDF/DOCX), or code reproduction packages were incorrectly flagged as datasets. Under Task 15.1, each deposit was screened against repository file manifests to guarantee the presence of primary data.
2. **Strict Machine Learning Task Formulation:** Datasets must support clear statistical learning paradigms (e.g. classification, object detection, segmentation, sequence labeling, ASR, or regression). Traditional wet-lab experimental records (e.g. crystal neutron scattering, XAFS spectra, nanoparticle synthesis) lacking ML evaluation objectives were removed.
3. **Modality & Task Rectification:** Corrected multiple misclassifications (e.g., Spotify Billboard Hot 100 features moved from audio to tabular; BD-AgroMet56 and soybean yield prediction moved from vision to tabular time-series; BanglaHateLens-3D moved from audio to NLP; HSC-IndicDB and BanglaHand recognized as vision).
4. **Licensing & Rights Verification:** Rights statements were confirmed directly from repository metadata. 100% of the 61 approved datasets feature verified open licenses (58 CC BY 4.0, 2 CC BY-SA 4.0, 1 CC0 1.0 Universal).
5. **Duplicate & Derivative Audit:** Pairwise comparisons verified zero DOI collisions and zero exact duplicate releases against both the original 101 catalog and other candidate deposits. Distinct guava disease collections from different research teams were verified as separate non-overlapping datasets.
