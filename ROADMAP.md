# OpenDatasets roadmap

This roadmap separates available functionality from proposed work. It is not a delivery-date commitment.

## Available

- Dataset search, category browsing, and detail pages.
- Structured metadata records with source references and license/access information.
- Offline schema validation, URL syntax checks, and duplicate ID/slug checks.
- Generated catalog and automated Python/frontend CI checks.

## Next priorities

- Public demo with working direct links and refresh behavior.
- Clear metadata-verification wording throughout the UI.
- Audit missing metadata against original sources and retain explicit unknown values.
- Keyboard navigation, focus visibility, and mobile usability review.
- Screenshots and a short walkthrough in the project README.

See [open issues](https://github.com/VisionX25/OpenDatasets/issues) for scoped tasks and acceptance criteria.

## Later exploration

- Automated source-link health reporting, distinct from offline validation.
- Optional data profiling with documented methods and reproducible results.
- FastAPI endpoints and ingestion only when justified by catalog needs.
- Carefully sourced Bangladesh-relevant datasets with clear access and reuse terms.

Suggest changes through an issue and explain the user problem and evidence.
